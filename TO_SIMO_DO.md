# AZIONI MANUALI RICHIESTE

## Icone PWA (Progressive Web App)
- Quando deciderai il logo ufficiale dell'app, ricordati di generare e inserire nella cartella `artifacts/gestionale/public/` le seguenti icone per la PWA:
  1. `pwa-192x192.png`
  2. `pwa-512x512.png`
  3. `apple-touch-icon.png` (formato raccomandato per iOS)
  
  Queste icone sono già configurate nel file `vite.config.ts`, ti basterà inserirle con questi esatti nomi.
